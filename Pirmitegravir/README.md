# Pirmitegravir (a.k.a. PIR, STP0404)
## The current folder contains the following files:
- PIR.pdb : Geometry optimized coordinates.
- PIR.str : CHARMM-compatible topology and QM optimized parameters.
- PIR.cif : Ligand restraint definitions for refinement in PHENIX.
- README.md : This file :) .
- LICENSE :  HIVff license and terms of use.

**Inhibitor Type:** Allosteric Integrase Inhibitor (ALLINI), LEDGF-IN site inhibitor (LEDGIN)
