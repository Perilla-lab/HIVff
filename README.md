# HIV-1 inhibitor force-field (HIVff) repository

Here you can find QM-derived CHARMM force-field parameters for various drug inhibitors of the HIV-1 virus.

Pfizer (PF)
Gilead Science (GS)

Type abbreviations:
- Maturation inhibitor (MI)
- Capsid inhibitor (CI)
- Allosteric integrase inhibitor (ALLINI)
- Integrase strand transfer inhibitor (INSTI)
